SOBRE NOSOTROS

Tecnología con un propósito.

Somos un equipo conformado por 3 aprendices SENA Guillermo Bautista, Esteban Garavito y Yilber Cely Estamos en formación del programa de Tegnología en instrmentación y control industrial, tomamos este proyecto como una oportunidad de aplicar los conocimientos adquiridos en el programa y desarrollar habilidades prácticas en el campo de la instrumentación y control industrial. Contamos con el apoyo de nuestro instructor, el ingeniero Eric Hernández, quien nos ha brindado orientación y supervisión en el desarrollo del proyecto, asegurando que se cumplan los estándares de calidad y seguridad.

AquaSense es una propuesta tecnológica orientada a visualizar el nivel de un estanque y facilitar la identificación de cambios importantes.

AQ
INNOVACIÓN · AGUA · TECNOLOGÍA
03 / CONOCE AQUASENSE

Una visión más inteligente
del nivel del agua.

El proyecto busca medir el nivel de agua de un estanque mediante sensores y tarjetas electrónicas, para después mostrar la información en una interfaz web.

01
⌁

Captura de datos

Un sensor medirá el nivel del agua y enviará la lectura a la electrónica del sistema.

02
⇄

Comunicación

Las tarjetas Heltec y LilyGO podrán intercambiar datos cuando se configure el enlace adecuado.

03
▤

Visualización web

La interfaz mostrará el nivel, el estado y las alertas a partir de datos recibidos.

EL SIGUIENTE PASO

De una demostración a datos reales.

Primero validaremos el sensor y la comunicación; después conectaremos el panel web.
